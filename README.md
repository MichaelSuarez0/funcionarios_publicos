# funcionarios_publicos
Proyecto personal para obtener datos de los +40 000 funcionarios públicos peruanos del Directorio Nacional de Funcionarios Públicos. Demora alrededor de ~2 horas.

# Uso

Clonar el repositorio

```bash
git clone https://github.com/MichaelSuarez0/funcionarios_publicos.git
```

Instalar las librerías necesarias

```bash
cd funcionarios_publicos
uv sync
```

Correr el scraper

```bash
uv run main.py
```
